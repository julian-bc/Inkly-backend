# Inkly API
![banner readme](./assets/banner.gif)

Inkly API es la interfaz que potencia Inkly, una plataforma inspirada en el estilo de Wattpad, diseñada para que escritores y lectores compartan y descubran historias dentro de una comunidad vibrante.

El repositorio actual contiene los módulos de **usuarios**, **API Gateway**, **notificaciones** y **seguridad**.

El repositorio [Inkly Core](https://github.com/LiangCamilo/story-service) corresponde al **backend del negocio**, con la lógica de **historias** y **comentarios** de la aplicación.

## Tecnologías
- Spring Cloud
- Keycloak
- RabbitMQ
- Docker
